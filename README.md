# 🔥 idea烤串机

> 把你的产品想法架在火上烤一烤 —— 五位 AI 评委轮番毒舌，现烤一份「存活评估报告」。

**一个输入框 + 一个按钮，得到一份由五位 AI 评委现烤的产品诊断报告。** 段子是演的，产品常识是真的：这里的每一句吐槽背后，都是一套可执行的评测逻辑。

## ✨ 它是什么

输入你的产品 idea（一句话就行），五位评委按固定顺序轮番开火：

1. **毒舌投资人 · Vincent 沈** —— 只认数字，先谈钱再谈壁垒
2. **真实用户 · 小李** —— 28 岁，手机里 47 个 App，注册表单超过 3 个字段就放弃
3. **暴躁工程师 · 阿健** —— 不攻击人，只攻击排期
4. **法务 · 陈律师** —— 上线检查清单的活人版
5. **竞品 PM · Kevin** —— 永远比你多跑一次 A/B 测试

每位评委的吐槽都**必须引用你原话里的关键词**（证明他真的读了），并附一句 💡 **建设性建议**——不是纯喷，是能拿去改的。

烤完出一份**完整报告**：五维雷达图（需求真伪 / 护城河 / 技术可行性 / 商业模式 / 抗喷度）、综合存活分、评级印章（米其林级 / 夜市级 / 碳烤级…）、主厨判词、三条改进建议。

## 🚀 快速开始

### 直接体验

整个站点是一个自包含的 `index.html`（HTML + CSS + JS 全部内联），**双击打开即可运行**，无需安装、无需构建、无需后端。数据保存在浏览器 localStorage，仅本机可见。

### 接入真实大模型（可选，强烈推荐）

未配置时使用内置演示引擎拼装吐槽（可离线体验）；配置 OpenAI 兼容 API 后由真实大模型现烤，体验完全不同。

1. 点击顶栏「演示模式」→ 打开 API 设置
2. 选择预设（DeepSeek / Moonshot / OpenAI / 硅基流动）或自定义
3. 填入 `Base URL` + `API Key` + `模型名`，点「保存并测试」

> DeepSeek 预设：`https://api.deepseek.com/v1` + `deepseek-v4-flash`（或更稳的 `deepseek-v4-pro` / `deepseek-chat`）。
> 一次完整烤制需生成 5 段发言 + 打分，约 15~40 秒属正常；境外接口（如 OpenAI）在国内直连需代理。

## 🧠 设计理念

这个项目本身也是一次产品实验：

- **多角色系统的关键在编排**：谁先说、说什么层次、什么不能说——投资人先谈钱，用户谈场景，工程师谈成本，法务谈红线，竞品补刀，模拟真实评审的火力递进
- **批评必须可验证、可回应**：每条吐槽强制引用原话关键词，这是「烤」和「喷」的分界线
- **情绪负责氛围，信息必须来自结构**：脾气可以暴躁，内容必须落到具体维度
- **问答即优化**：落地问诊的每一轮选择，都是在帮你把模糊的想法变成可执行的产品决策

## ❓ 常见问题

- **API 报错/超时？** 一次完整烤制需生成 800~1000 tokens，15~40 秒正常；遇到 5xx / 截断提示，请稍后重试或换 `deepseek-v4-pro`。已内置自动重试与中文错误提示。
- **跨域报错？** 接口需允许浏览器 CORS（DeepSeek 已支持）；不支持的可换服务或自建后端代理。
- **数据会丢吗？** 档案、战绩、API Key 都存在浏览器 localStorage，换设备/清缓存会清空，请勿存放敏感信息。
